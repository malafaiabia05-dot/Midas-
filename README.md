# Midas - Câmbio de Moedas

O **Midas** é um site interativo desenvolvido para apresentar informações atualizadas, gráficos comparativos e cotações de diversas moedas do mundo, proporcionando dados de qualidade para o usuário.

## 🔗 Links Úteis
- **Site Publicado (Render):** https://midas-vc2a.onrender.com

## 🚀 Funcionalidades

- **Cotações em Tempo Real:** Consulta de valores de mais de 20 moedas utilizando a **AwesomeAPI**.
- **Gráficos Dinâmicos:** Visualização de dados de comparação, cotação e distribuição de informações por continentes utilizando o **Chart.js**.
- **CRUD com Back-end:** Sistema de cadastro e gerenciamento onde o usuário cria uma conta para salvar o valor de compra desejado para adquirir uma moeda no futuro (integrado com o Back4App).

## 🛠️ Tecnologias Utilizadas

- **HTML5, CSS3 e JavaScript (ES6+)**
- **Bootstrap** (para estilização rápida e design responsivo em celulares e desktops)
- **Chart.js** (para a criação dos gráficos do dashboard)
- **AwesomeAPI** (API pública de cotação de moedas)
- **Back4App / Parse SDK** (para o back-end e banco de dados do CRUD)
- **render e GitHub** (para versionamento do código e construção do código)
